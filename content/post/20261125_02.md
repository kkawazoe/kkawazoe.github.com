Ruby 4.0 リリースノートについてまとめたものを備忘録として残しておく

Ruby 4.0.0 は 2025-12-25 にリリースされた  
本記事は公式のリリースアナウンスと NEWS.md (Ruby 3.4.0 からの変更点) をもとにまとめている

Ruby 4.0 のリリースノートは以下の通り

## Ruby 4.0 での主な新機能

### Ruby Box (実験的機能)

* クラスなどの定義を分離・隔離する実験的機能として `Ruby::Box` が導入された
* 環境変数 `RUBY_BOX=1` を指定すると有効になる
* 以下が Box ごとに隔離される
  * 既存クラスへのモンキーパッチ
  * グローバル変数・クラス変数の変更
  * クラス / モジュールの定義
  * `.rb` ファイルや拡張ライブラリとして実装されたライブラリ
* 想定されているユースケースは以下の通り
  * 挙動を上書きするモンキーパッチを必要とするテストを Box 内で実行する
  * Web アプリケーションを Box 内で動かし、同一プロセス内で Blue-Green デプロイを行う
  * 依存ライブラリを更新する際に、新旧を一定期間並行稼働させてレスポンスを比較する
  * 将来の「パッケージ API」のような高水準 API の基盤として使う

### ZJIT

* YJIT の次世代となる、メソッドベースの新しい JIT コンパイラ ZJIT が導入された
* `--zjit` オプション、または `RubyVM::ZJIT.enable` で有効化できる
* ZJIT を含めてビルドするには Rust 1.85.0 以降が必要
* 4.0.0 時点ではインタプリタより速いが、YJIT には及ばない
  * 試すことは推奨されているが、本番環境での利用は現時点では推奨されていない
  * Ruby 4.1 で YJIT より高速かつ本番利用可能にすることが目標とされている

### Ractor の改善

* Ractor 間の通信手段として `Ractor::Port` が追加された
* `Ractor.shareable_proc` / `Ractor.shareable_lambda` で Ractor 間で共有可能な Proc / lambda を作れるようになった
* 内部データ構造の改善により、グローバルロックの競合や CPU キャッシュの競合が大幅に減った
* 実験的機能 (experimental) のステータスを外す段階に近づいたとされている

## 言語仕様の変更

* `*nil` が `nil.to_a` を呼ばなくなった (`**nil` が `nil.to_hash` を呼ばないのと同様)
* 行頭の論理二項演算子 (`||`, `&&`, `and`, `or`) が、メソッドチェーンの `.` と同じように前の行の続きとして扱われるようになった

    ```ruby
    if condition1
       && condition2
      ...
    end
    ```

## コアクラスの更新

### Array

* `array.reverse_each.find` の効率的な代替として `Array#rfind` が追加された
* `Enumerable#find` をより効率的に上書きする `Array#find` が追加された

### Binding

* `Binding#local_variables` が番号付きパラメータを含まなくなった
  * `local_variable_get` / `local_variable_set` / `local_variable_defined?` も番号付きパラメータを扱わなくなった
* 番号付きパラメータと `it` パラメータを扱う以下のメソッドが追加された
  * `Binding#implicit_parameters`
  * `Binding#implicit_parameter_get`
  * `Binding#implicit_parameter_defined?`

### Enumerator

* `Enumerator.produce` が列挙子のサイズを指定する `size:` キーワード引数を受け付けるようになった
  * 整数 / `Float::INFINITY` / 呼び出し可能オブジェクト (lambda など) / 不明を表す `nil` を指定できる
  * 省略時は `Float::INFINITY`

    ```ruby
    enum = Enumerator.produce(1, size: Float::INFINITY, &:succ)
    enum.size  # => Float::INFINITY
    ```

### ErrorHighlight

* `ArgumentError` 発生時に、呼び出し側 (caller) と定義側 (callee) の両方のコードスニペットが表示されるようになった

    ```text
    test.rb:1:in 'Object#add': wrong number of arguments (given 1, expected 2) (ArgumentError)

        caller: test.rb:3
        | add(1)
          ^^^
        callee: test.rb:1
        | def add(x, y) = x + y
              ^^^
            from test.rb:3:in '<main>'
    ```

### Fiber / Fiber::Scheduler

* `Kernel#raise` と同様に `Fiber#raise(cause:)` が使えるようになった
* 指定した例外でファイバを中断する `Fiber::Scheduler#fiber_interrupt` が追加された
  * IO が閉じられたときに、その IO を待っているファイバを中断する用途を想定している
* シグナル例外が無効な場合でもスケジューラが処理を続けられるよう `Fiber::Scheduler#yield` が追加された
* 非同期の `IO#close` 用に `Fiber::Scheduler#io_close` フックが再導入された
* IO の書き込みバッファを flush する際に `Fiber::Scheduler#io_write` が呼ばれるようになった

### File

* カーネルとファイルシステムが対応していれば、Linux でも statx システムコール経由で `File::Stat#birthtime` が使えるようになった

### IO

* `IO.select` のタイムアウト引数に `Float::INFINITY` を指定できるようになった
* 非推奨だった、先頭に `|` を付けた `IO` クラスメソッドによるプロセス生成が削除された

### Kernel

* `Kernel#inspect` が `instance_variables_to_inspect` メソッドを参照し、`inspect` に表示するインスタンス変数を制御できるようになった

    ```ruby
    class DatabaseConfig
      def initialize(host, user, password)
        @host = host
        @user = user
        @password = password
      end

      private def instance_variables_to_inspect = [:@host, :@user]
    end

    conf = DatabaseConfig.new("localhost", "root", "hunter2")
    conf.inspect #=> #<DatabaseConfig:0x0000000104def350 @host="localhost", @user="root">
    ```

* 非推奨だった、先頭に `|` を付けた `Kernel#open` によるプロセス生成が削除された

### Math

* `Math.log1p` と `Math.expm1` が追加された

### Pathname

* default gem からコアクラスに昇格した

### Proc

* `Proc#parameters` が匿名のオプション引数を `[:opt, nil]` ではなく `[:opt]` と表示するようになった

### Ractor

* `Ractor::Port` が追加された
  * 使えるメソッドは `receive` / `send` (`<<`) / `close` / `closed?`

    ```ruby
    port1 = Ractor::Port.new
    port2 = Ractor::Port.new
    Ractor.new port1, port2 do |port1, port2|
      port1 << 1
      port2 << 11
      port1 << 2
      port2 << 12
    end
    2.times{ p port1.receive } #=> 1, 2
    2.times{ p port2.receive } #=> 11, 12
    ```

* Ractor の終了を待つ `Ractor#join` / `Ractor#value` が追加された (`Thread#join` / `Thread#value` 相当)
* `Ractor#join` の実装に使われる低レベル API として `Ractor#monitor` / `Ractor#unmonitor` が追加された
* `Ractor.select` が Ractor と Port のみを受け付けるようになった
* `Ractor#default_port` が追加された
  * 各 Ractor はデフォルトのポートを持ち、`Ractor.send` / `Ractor.receive` で使われる
* `Ractor.shareable_proc` / `Ractor.shareable_lambda` が追加された

### Range

* `Range#to_set` が終端のない範囲で問題が起きないようサイズチェックを行うようになった
* `Range#overlap?` が無限 (終端のない) 範囲を正しく扱うようになった
* 始端のない整数範囲での `Range#max` の挙動が修正された

### Ruby

* Ruby に関する定数を持つトップレベルモジュール `Ruby` が正式に定義された (Ruby 3.4 で予約済みだったもの)

### Set

* 自動ロードされる標準ライブラリのクラスから、コアクラスになった
* `Set#inspect` の表示が `#<Set: {1, 2, 3}>` から `Set[1, 2, 3]` に変わった
* `Set#to_set` と `Enumerable#to_set` に引数を渡すことが非推奨になった

### Socket

* `Socket.tcp` と `TCPSocket.new` が初回接続のタイムアウトを指定する `open_timeout:` キーワード引数を受け付けるようになった
* `TCPSocket.new` でユーザー指定のタイムアウトが発生した場合は、一貫して `IO::TimeoutError` が発生するようになった
  * `Socket.tcp` では引き続き `Errno::ETIMEDOUT` になる場合がある
  * OS レベルでタイムアウトした場合は、どちらも `Errno::ETIMEDOUT` になる場合がある

### String

* Unicode が 17.0.0、Emoji が 17.0 に更新された (Regexp にも適用)
* `strip` / `strip!` / `lstrip` / `lstrip!` / `rstrip` / `rstrip!` が `*selectors` 引数を受け付けるようになった

### Thread

* `Kernel#raise` と同様に `Thread#raise(cause:)` が使えるようになった

  * Visual Studio 2015 以降が必須になった

## 非推奨および削除された機能 (互換性に関する変更)

### コア

* `Ractor::Port` の追加に伴い、以下が削除された
  * `Ractor.yield`
  * `Ractor#take`
  * `Ractor#close_incoming`
  * `Ractor#close_outgoing`
* `ObjectSpace._id2ref` が非推奨になった
* Ruby 3.3 で非推奨になっていた `Process::Status#&` と `Process::Status#>>` が削除された
* 非推奨だった C 関数 `rb_path_check` が削除された
* 引数の数が誤っている場合の `ArgumentError` のバックトレースに、レシーバのクラス / モジュール名が含まれるようになった
  * 例: `in 'bar'` ではなく `in 'Foo#bar'`
* バックトレースに `internal` フレームが表示されなくなった

    変更前

    ```text
    $ ruby -e '[1].fetch_values(42)'
    <internal:array>:211:in 'Array#fetch': index 42 outside of array bounds: -1...1 (IndexError)
            from <internal:array>:211:in 'block in Array#fetch_values'
            from <internal:array>:211:in 'Array#map!'
            from <internal:array>:211:in 'Array#fetch_values'
            from -e:1:in '<main>'
    ```

    変更後

    ```text
    $ ruby -e '[1].fetch_values(42)'
    -e:1:in 'Array#fetch_values': index 42 outside of array bounds: -1...1 (IndexError)
            from -e:1:in '<main>'
    ```

### 標準ライブラリ

* CGI ライブラリが default gem から削除された
  * `cgi/escape` のみ残り、以下のメソッドは引き続き使える
    * `CGI.escape` / `CGI.unescape`
    * `CGI.escapeHTML` / `CGI.unescapeHTML`
    * `CGI.escapeURIComponent` / `CGI.unescapeURIComponent`
    * `CGI.escapeElement` / `CGI.unescapeElement`
* `Set` のコアクラス化に伴い `set/sorted_set.rb` が削除され、`SortedSet` が自動ロードされなくなった
  * 使う場合は `sorted_set` gem をインストールして `require 'sorted_set'` する
* Net::HTTP で、body を持つリクエスト (`POST`, `PUT` など) に `Content-Type` が未指定のとき `application/x-www-form-urlencoded` を自動で設定する挙動が削除された
  * この自動設定に依存していた場合、`Content-Type` なしで送信されるため一部のサーバーと互換性がなくなる可能性がある

## C API の更新

* `rb_thread_fd_close` が非推奨になり、何もしなくなった
  * C 拡張から Ruby にファイルディスクリプタを公開する場合は、`RUBY_IO_MODE_EXTERNAL` で `IO` を作成し、`rb_io_close(io)` で閉じる
* `rb_thread_call_with_gvl` が GVL の有無にかかわらず動作するようになった
  * gem 側で `ruby_thread_has_gvl_p` を確認する必要がなくなった
* `Set` の C API が追加された
  * `rb_set_foreach` / `rb_set_new` / `rb_set_new_capa` / `rb_set_lookup` / `rb_set_add` / `rb_set_clear` / `rb_set_delete` / `rb_set_size`

## 実装の改善

* `Class#new` (例: `Object.new`) が全般的に高速化された
  * 特にキーワード引数を渡す場合に効果が大きく、YJIT / ZJIT にも反映されている
* サイズプールごとの GC ヒープが独立して拡張されるようになり、一部のプールにだけ長寿命オブジェクトがある場合のメモリ使用量が減った
* 大きなオブジェクトのページの GC スイープが高速化された
* String / Array / `TypedData` などの「Generic ivar」オブジェクトのインスタンス変数アクセスが高速化された
* GC が内部の `id2ref` テーブルを初回使用まで保持しなくなり、`object_id` の割り当てと GC スイープが高速化された
* Class / Module の `object_id` と `hash` が高速化された
* 大きな多倍長整数 (Bignum) も可変幅アロケーションで埋め込みのまま保持できるようになった
* `Random` / `Enumerator::Product` / `Enumerator::Chain` / `Addrinfo` / `StringScanner` などがライトバリア対応になり、GC のオーバーヘッドが減った

### Ractor の実装改善

* パフォーマンス改善
  * 凍結文字列とシンボルテーブルでロックフリーのハッシュセットが使われるようになった
  * メソッドキャッシュの参照、クラスのインスタンス変数アクセス、`object_id` でほとんどの場合ロックを取らなくなった
  * オブジェクト割り当てや xmalloc / xfree での CPU キャッシュ競合が回避されるようになった
* バグ修正・安定性
  * Ractor と Thread を組み合わせた場合のデッドロックが修正された
  * Ractor 内での require / autoload の問題が修正された
  * Ractor 間のエンコーディング / トランスコードの問題が修正された
  * GC 操作とメソッド無効化の競合状態が修正された
  * Ractor 起動後に fork した場合の問題が修正された
  * GC 後に TracePoint が動かない問題が修正された

## JIT

### ZJIT の位置付け

* 実験的なメソッドベースの JIT コンパイラとして導入された (詳細は [主な新機能の ZJIT](#zjit) を参照)

### YJIT

* `RubyVM::YJIT.runtime_stats` の `ratio_in_yjit` がデフォルトのビルドでは使えなくなった
  * 使う場合は `configure` に `--enable-yjit=stats` を付けてビルドし、`--yjit-stats` で有効にする
* TracePoint によってすべてのコードが無効化された回数を示す `invalidate_everything` がデフォルトの統計に追加された
* `RubyVM::YJIT.enable` に `mem_size:` / `call_threshold:` オプションが追加された

### RJIT

* `--rjit` が削除された
  * サードパーティ JIT API の実装は [ruby/rjit](https://github.com/ruby/rjit) リポジトリに移される
